지각 기록 시스템 사용설명서

학번만 입력하면 이름이 뜨고, 시각을 기록하면 반별·기간별 통계가 자동으로 쌓입니다. 여러 선생님이 동시에 쓰셔도 각자 기록이 안전하게 저장됩니다.

시작하기

주소로 들어가서 공용 비밀번호만 입력하면 됩니다. 계정을 따로 만들 필요는 없습니다.

  1. 1위 접속 주소로 이동합니다.
  2. 2비밀번호에 학생부 공용 비밀번호를 입력합니다.
  3. 3입력자 성함은 선택 사항이지만, 나중에 누가 기록했는지 구분하고 싶다면 적어 주세요. 최근 기록 목록에 이름이 함께 표시됩니다.
  4. 4입장하기를 누르면 로그인이 30일간 유지됩니다 — 매번 다시 입력할 필요 없습니다.

2

지각 기록하기

가장 자주 쓰게 될 화면입니다. 학번 네 자리만 알면 10초 안에 기록이 끝납니다.

  1. 1학번 입력 칸에 학번을 입력하고 조회를 누릅니다. (예: 2101 → 2학년 1반 1번)
  2. 2학생 이름·학년·반·번호가 맞는지 확인합니다.
  3. 3지각 시각은 기본값이 지금 시각이며, 필요하면 직접 바꿀 수 있습니다.
  4. 4사유는 선택 입력입니다.
  5. 5지각 기록 저장을 누르면 완료 — 오늘 몇 번째, 이번 학기 몇 번째 지각인지도 바로 알려줍니다.

3

최근 기록 확인·정정

지각 입력 화면 아래쪽에 최근 기록이 항상 떠 있고, 8초마다 자동으로 갱신됩니다. 다른 선생님이 방금 입력한 것도 바로 보입니다.

최근 기록
  • 2학년 1반 1번 강우진 9. 17. 오전 08:12 · 김선생 삭제
  • 1학년 3반 1번 김도영 9. 17. 오전 08:09 (늦잠) 정말 삭제 취소

기록을 잘못 입력했다면, 수정 기능 대신 삭제 후 재입력하는 방식입니다. 삭제를 누르면 실수 방지를 위해 한 번 더 정말 삭제를 눌러야 실제로 지워집니다.

4

통계 보기 (대시보드)

상단 메뉴의 대시보드에서 반별·기간별 지각 현황을 한눈에 봅니다.

  1. 1일간 / 주간 / 월간 / 학기 / 연간 중 원하는 기간을 고릅니다. 학기는 3~8월(1학기), 9월~익년 2월(2학기)로 자동 구분됩니다.
  2. 2날짜를 바꾸면 그 날짜가 포함된 기간으로 다시 계산됩니다.
  3. 3학년 필터로 특정 학년만 따로 볼 수 있습니다.
  4. 4반별 지각 건수 그래프, 기간 추이 그래프, 지각 많은 학생 Top 10까지 함께 제공됩니다.

학생 명단 관리

신학기가 시작되거나 반 편성·전학생이 생겼을 때, 학교 학생 명렬 엑셀 파일을 다시 올리면 학번을 기준으로 자동 반영됩니다.

  1. 1상단 메뉴 학생 명단 관리로 들어갑니다.
  2. 2학교 학생 명렬 엑셀(.xlsx) 파일을 선택합니다. 전체를 한 번에 올려도 되고, 학년별로 나눠 올려도 됩니다.
  3. 3업로드가 끝나면 신규/갱신 인원수가 표시됩니다. 이미 있는 학번은 정보만 갱신되고, 새 학번은 새로 추가됩니다.
  4. 4전학 등으로 없어진 학생은 목록에서 비활성화할 수 있습니다 — 지각 기록은 남지만 새 지각 입력 시 조회되지 않습니다.

자주 묻는 질문

Q공용 비밀번호를 잊어버렸어요.
학생부 담당 선생님(또는 이 시스템을 배포한 담당자)에게 문의하세요. 비밀번호는 서버 설정에서 바로 확인·변경할 수 있습니다.
Q학번을 입력했는데 "학생을 찾을 수 없습니다"라고 나와요.
학번을 잘못 입력했거나, 아직 명단에 없는 학생(신입생·전학생)일 수 있습니다. 학생 명단 관리에서 검색해 확인하고, 없다면 최신 명단 엑셀을 다시 업로드해 주세요.
Q지각 시각이나 학생을 잘못 입력했어요. 수정할 수 있나요?
별도의 수정 기능은 없고, 삭제 후 다시 입력하는 방식입니다. 최근 기록 목록에서 삭제 → 정말 삭제를 누른 뒤 새로 기록하세요.
Q동시에 여러 명이 입력해도 기록이 꼬이지 않나요?
그렇지 않습니다. 각 지각 기록은 독립된 항목으로 저장되며, 같은 학생이라도 여러 건이 각각 남습니다. 최근 기록 목록은 8초마다 자동으로 갱신되어 다른 선생님의 입력도 바로 확인됩니다.
Q1학기·2학기 구분은 어떻게 되나요?
3월 1일~8월 31일이 1학기, 9월 1일~다음 해 2월 말일이 2학기로 자동 계산됩니다. 별도로 설정할 필요가 없습니다.
Q휴대폰으로도 쓸 수 있나요?
네. 화면이 휴대폰 크기에 맞게 자동으로 조정되며, 조회·저장·대시보드 확인 모두 휴대폰 브라우저에서 그대로 가능합니다.
